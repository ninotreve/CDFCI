# 加长实验的最终数据选择

最终只采用本轮 **C2 300万步**和 **N2 260万步**正式数据，详细结果、来源与重分析方法见 [RESULTS_DEFERRED.md](RESULTS_DEFERRED.md)。

原 C2 `1022419` 请求 360 万步，raw 与 IP+Olsen 完成，IP-only 在报告 347 万步后超时。因此三组的前 300 万步（各 300 个报告点）仍是完整的同 bigMem5、同 allocation 对照。原作业状态保留 TIMEOUT；不能将其改称完整完成。

N2 `1022420` 的三组 260 万步均成功完成，各有 260 个报告点。

曾尝试的 C2 IP-only 补跑 `1024227` 被移到 bigMem3，后来因用户选择原同节点 300 万步前缀而取消。它的计时不参与结果。无用补跑输出、脚本、日志及不再发布的 C2 全长源文件已从仓库工作树移到仓库外可恢复归档，不纳入提交；C2 发布的 JSON/stdout 源片段只包含 <=300 万步的报告。

`run_three_way.sbatch` 的后续默认设置改为 C2 300 万 / N2 260 万步，其他生产参数不变。运行时 manifest 的源码与脚本哈希代表原实际提交版本，不替换为本次发布/默认值调整后的版本。
